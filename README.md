# HIKA

Голосовое управление Windows. Живёт в трее, слушает микрофон, откликается
на **«Хика»** и **«Ави»**, подсвечивает края экрана в такт голосу и открывает
то, что попросили.

Команды выполняет молча — действие видно и так. На вопросы отвечает вслух
нейроголосом и подстраивается под то, как говорите именно вы.

```
Ави, открой ютуб
Хика, запусти телеграм
Ави, ютуб
Привет, Ави, открой ворд
Hey Avi, open Chrome
Ави, сделай громче
Ави, сверни всё
Ави, перемотай назад                     — ютубу и любому плееру
Ави, включи субтитры

Ави, расскажи, что такое чёрная дыра     — ответит голосом
Ави, а почему?                           — продолжит без имени
```

Имя можно и не произносить: **Ctrl+Alt+Space** — нажал, сказал команду,
выполнилось, снова спит.

Умеет диктовать: «Ави, диктую» — и дальше всё сказанное набирается
в активное окно, со знаками препинания, названными вслух. «Стоп» — хватит.

---

## Как это выглядит

Прозвучало имя — по краям экрана разгорается кайма и начинает мерцать
в такт речи. Команда выполнена — короткая вспышка, и всё гаснет.

Пока имя не прозвучало, не происходит ничего: свечение означает ровно одно,
и мигать от любого звука в комнате оно не должно.

---

## Она объясняет себя сама

Настройки → **«Что происходит»** отвечает на два вопроса, которые возникают
у всех и на которые раньше нельзя было ответить, не открыв консоль.

**Почему медленно.** Полоса из трёх цветов: сколько ушло на ожидание вашей
паузы, сколько на распознавание, сколько на само действие. «Медленно» —
не диагноз: полторы секунды могут быть полутора секундами распознавания,
а могут — четырьмя сотнями миллисекунд ожидания плюс тем же распознаванием,
и лечится это в разных местах. Под полосой — что здесь виновато и одна
кнопка, которая это исправляет.

**Почему открыла не то.** Последние услышанные фразы и что с каждой стало.
Причина такой ошибки всегда одна из трёх — расслышала не то, разобрала
не так, нашла не ту программу, — и порознь они неразличимы. Непринятые
фразы тоже в списке: «она меня не слышит» почти всегда означает «имя
расслышано как другое слово», и увидеть, как именно, больше негде.

Ничего из этого не сохраняется на диск и не уходит наружу.

## Начать

Всё по шагам — в **[ТРЕБУЕТСЯ-ОТ-ТЕБЯ.md](ТРЕБУЕТСЯ-ОТ-ТЕБЯ.md)**.
Коротко:

```
dotnet publish src/Hika.App/Hika.App.csproj -c Release -o build
build\Hika.exe
```

Первый запуск качает около 200 МБ моделей. Дальше — сразу.

Если что-то не так: `build\Hika.exe --diagnose`

## Что внутри

```
микрофон ──► 16 кГц моно ──► Silero VAD ──► нарезка на фразы
                                                   │
                              ┌────────────────────┴───────────────┐
                              ▼                                    ▼
                    ранняя проверка имени                 фраза целиком
                    (пока человек говорит)                       │
                              │                                  ▼
                              ▼                              Whisper
                        кайма загорается                        │
                                                                 ▼
                                                    имя ─► команда ─► запуск
```

Распознавание считается на этом компьютере. В сеть уходит скачивание моделей
при первом запуске — и, если вы сами включите разговор, текст вопроса
и ответа. **Записанный звук не покидает машину никогда.**

| Слой | Чем сделано |
|---|---|
| Захват звука | WASAPI через NAudio, приведение к 16 кГц моно |
| Детектор речи | Silero VAD, запасной — энергетический |
| Распознавание | whisper.cpp через Whisper.net |
| Понимание команд | Правила и нечёткое сравнение, без языковой модели |
| Свечение | Слоистые окна с попиксельной прозрачностью |
| Голос | Нейроголоса Windows, при желании — нейроголоса Microsoft |
| Разговор | Claude по вашему ключу; включается отдельно, по умолчанию выключен |
| Обучение | Словарь-подсказка, синонимы и написания имени из вашей же речи |

Код разложен на две части: `src/Hika.Core` — разбор текста и каталог,
обычный `net9.0` без привязки к системе; `src/Hika.App` — всё, что без
Windows не имеет смысла. Благодаря этому логику разбора русских команд
можно проверить тестами где угодно, а не только на Windows:

```
./build.sh          тесты + компиляция под Windows
./build.sh test     только тесты (полсекунды)
```

Подробнее: [docs/АРХИТЕКТУРА.md](docs/АРХИТЕКТУРА.md)

## Русский язык

Он здесь главный, и под него сделано несколько отдельных вещей.

**Распознавание работает в русском режиме, а не с автоопределением языка.**
На фразе длиной в секунду («Ави, ютуб») автоопределение ненадёжно и уводит
модель не туда.

**Модели подсказывают наш словарь.** «Ави» и «Хика» — не слова русского языка,
и без подсказки Whisper их коверкает. Список слов пробуждения и названий
программ передаётся модели как затравка.

**Кириллица и латиница сводятся к общему звуковому написанию.** Поэтому
«фотошоп» находит Photoshop, «ворд» — Word, «эксель» — Excel, хотя ни одно
из этих написаний не совпадает буквально:

```
фотошоп → fotoshop     photoshop → fotoshop     совпало точно
ворд    → vord         word      → vord         совпало точно
твич    → tvich        twitch    → tvich        совпало точно
стим    → stim         steam     → stim         совпало точно
гугл    → gugl         google    → gugl         совпало точно
хром    → hrom         chrome    → chrom        разница в один символ
```

Побочная выгода: английские команды, приезжающие от модели кириллицей
(«опен ворд»), доходят по назначению.

**Отсев выдумок модели.** Whisper на тишине уверенно выдаёт куски, которых
никто не произносил — «Субтитры сделал DimaTorzok», «Продолжение следует...»,
«Спасибо за просмотр!». Это следы обучения на субтитрах с YouTube, и без
фильтра ассистент оживал бы от кашля и хлопнувшей двери.

**Слову пробуждения прощается расхождение по длине слова.** Трёхбуквенному
«Ави» — ровно одна ошибка, иначе оно начнёт совпадать с каждым вторым словом.

## Настройки

Щелчок по значку в трее. Одиннадцать разделов, у каждой настройки написано
обычными словами, что она делает и чем оборачивается. Отдельно стоят два:

- **«Что я умею»** — весь список команд, который можно читать глазами.
  Каждый пример в нём проверяется тестом на то, что он действительно
  разбирается в обещанную команду.
- **«Что происходит»** — из чего сложилось ожидание, приговор словами
  и одна кнопка, которая чинит названную причину. Плюс список услышанного:
  что она разобрала и что с этим сделала. Щелчок по непонятой фразе ведёт
  в «Свои команды» с уже вписанной фразой.

Всё то же лежит в `%APPDATA%\HIKA\config.json` — перечитывается на лету,
перезапуск не нужен. Чужие ключи в файле сохраняются.

Самое ходовое:

| Ключ | Смысл |
|---|---|
| `wake.words` | Слова пробуждения |
| `wake.extraVariants` | Как модель реально расслышала имя — самый действенный способ подстройки |
| `speech.model` | `small` или `largev3turbo` для заметно лучшего русского |
| `audio.device` | Часть имени микрофона; пусто — устройство по умолчанию |
| `audio.gain` | Усиление тихого микрофона, `2.0`–`3.0` |
| `overlay.maxOpacity` | Яркость каймы; смысл настройки — не засветить экран |
| `overlay.showBeforeWakeWord` | Светиться ли до того, как услышано имя. Выключено: иначе кайма мигает от любого звука |
| `overlay.thickness` | Толщина каймы в долях меньшей стороны экрана |
| `overlay.colors` | Четыре цвета углов, между ними идёт переход |
| `behavior.listenHotkey` | Клавиша «слушай»: нажал — говоришь без имени, выполнила — спит |
| `behavior.muteHotkey` | Клавиша выключения микрофона |
| `custom` | Свои команды: фраза → что открыть |
| `voice.engine` | Откуда брать голос: `auto`, `windows`, `edge`, `off` |
| `brain.enabled` | Отвечать на вопросы через Claude (нужен ключ) |
| `learning.enabled` | Наблюдать за речью и подстраиваться |

Полный разбор: [docs/НАСТРОЙКА.md](docs/НАСТРОЙКА.md)

## Что оно умеет говорить

Спросить можно прямо у неё: «Ави, что ты умеешь» — откроется список,
разобранный по разделам. Он же в меню значка и открывается сам при первом
запуске.

## Безопасность

Обычные права пользователя, никаких перехватов, никакого внедрения
в чужие процессы, никаких драйверов. Микрофон выключается одним щелчком
по значку в трее.

Границы, которые не обходятся, и почему это правильно:

## Состояние

Собирается под Windows, 665 тестов на разбор команд, обучение и подготовку
речи проходят.

Запуск программ, распознавание и свечение проверены на живой машине. Голос,
разговор и обучение написаны и собраны, но их поведение на настоящем
компьютере ещё предстоит выяснить — в первую очередь то, какие нейроголоса
окажутся установлены.

Список того, чего здесь намеренно нет, — в конце
[ТРЕБУЕТСЯ-ОТ-ТЕБЯ.md](ТРЕБУЕТСЯ-ОТ-ТЕБЯ.md).
