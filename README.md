# HIKA

Голосовое управление Windows. Живёт в трее, слушает микрофон, откликается
на **«Хика»** и **«Ави»**, подсвечивает края экрана в такт голосу и открывает
то, что попросили.

Ничего не отвечает — ни голосом, ни текстом. Только делает.

```
Ави, открой ютуб
Хика, запусти телеграм
Ави, ютуб
Привет, Ави, открой ворд
Hey Avi, open Chrome
Ави, сделай громче
Ави, сверни всё
```

---

## Как это выглядит

Начал говорить — по краям экрана появляется слабое свечение. Прозвучало
имя — кайма разгорается и начинает мерцать в такт речи. Команда выполнена —
короткая вспышка, и всё гаснет.

Если обращались не к ассистенту, свечение просто угасает: в худшем случае
человек заметит слабый отблеск по краям.

## Начать

Всё по шагам — в **[ТРЕБУЕТСЯ-ОТ-ТЕБЯ.md](ТРЕБУЕТСЯ-ОТ-ТЕБЯ.md)**.
Коротко:

```
dotnet publish src/Hika.App/Hika.App.csproj -c Release -o build
build\Hika.exe
```

Первый запуск качает около 200 МБ моделей. Дальше — сразу.

Если что-то не так: `build\Hika.exe --diagnose`

## Что внутри

```
микрофон ──► 16 кГц моно ──► Silero VAD ──► нарезка на фразы
                                                   │
                              ┌────────────────────┴───────────────┐
                              ▼                                    ▼
                    ранняя проверка имени                 фраза целиком
                    (пока человек говорит)                       │
                              │                                  ▼
                              ▼                              Whisper
                        кайма загорается                        │
                                                                 ▼
                                                    имя ─► команда ─► запуск
```

Всё считается на этом компьютере. В сеть уходит ровно одно — скачивание
моделей при первом запуске. Записанный звук не покидает машину никогда.

| Слой | Чем сделано |
|---|---|
| Захват звука | WASAPI через NAudio, приведение к 16 кГц моно |
| Детектор речи | Silero VAD, запасной — энергетический |
| Распознавание | whisper.cpp через Whisper.net |
| Понимание команд | Правила и нечёткое сравнение, без языковой модели |
| Свечение | Слоистые окна с попиксельной прозрачностью |

Подробнее: [docs/АРХИТЕКТУРА.md](docs/АРХИТЕКТУРА.md)

## Русский язык

Он здесь главный, и под него сделано несколько отдельных вещей.

**Распознавание работает в русском режиме, а не с автоопределением языка.**
На фразе длиной в секунду («Ави, ютуб») автоопределение ненадёжно и уводит
модель не туда.

**Модели подсказывают наш словарь.** «Ави» и «Хика» — не слова русского языка,
и без подсказки Whisper их коверкает. Список слов пробуждения и названий
программ передаётся модели как затравка.

**Кириллица и латиница сводятся к общему звуковому написанию.** Поэтому
«фотошоп» находит Photoshop, «ворд» — Word, «эксель» — Excel, хотя ни одно
из этих написаний не совпадает буквально:

```
фотошоп → fotoshop     photoshop → fotoshop     совпало точно
ворд    → vord         word      → vord         совпало точно
твич    → tvich        twitch    → tvich        совпало точно
стим    → stim         steam     → stim         совпало точно
гугл    → gugl         google    → gugl         совпало точно
хром    → hrom         chrome    → chrom        разница в один символ
```

Побочная выгода: английские команды, приезжающие от модели кириллицей
(«опен ворд»), доходят по назначению.

**Отсев выдумок модели.** Whisper на тишине уверенно выдаёт куски, которых
никто не произносил — «Субтитры сделал DimaTorzok», «Продолжение следует...»,
«Спасибо за просмотр!». Это следы обучения на субтитрах с YouTube, и без
фильтра ассистент оживал бы от кашля и хлопнувшей двери.

**Слову пробуждения прощается расхождение по длине слова.** Трёхбуквенному
«Ави» — ровно одна ошибка, иначе оно начнёт совпадать с каждым вторым словом.

## Настройки

`%APPDATA%\HIKA\config.json` — перечитывается на лету, перезапуск не нужен.

Самое ходовое:

| Ключ | Смысл |
|---|---|
| `wake.words` | Слова пробуждения |
| `wake.extraVariants` | Как модель реально расслышала имя — самый действенный способ подстройки |
| `speech.model` | `small` или `largev3turbo` для заметно лучшего русского |
| `audio.device` | Часть имени микрофона; пусто — устройство по умолчанию |
| `audio.gain` | Усиление тихого микрофона, `2.0`–`3.0` |
| `overlay.maxOpacity` | Яркость каймы; смысл настройки — не засветить экран |
| `overlay.thickness` | Толщина каймы в долях меньшей стороны экрана |
| `overlay.colors` | Четыре цвета углов, между ними идёт переход |
| `custom` | Свои команды: фраза → что открыть |

Полный разбор: [docs/НАСТРОЙКА.md](docs/НАСТРОЙКА.md)
