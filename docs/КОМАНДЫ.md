# Команды

## Как построена фраза

```
[обращение] ИМЯ [, ] [глагол] цель
```

Всё в квадратных скобках необязательно. Работают все варианты:

```
Ави, открой ютуб
Привет, Ави, открой ютуб
Эй, Хика, запусти ютуб
Ави ютуб
Hey Avi, open YouTube
```

**Имя можно назвать отдельно.** Скажешь просто «Ави» — кайма загорится
и будет ждать команду шесть секунд. Успел сказать за это время — сработает:

```
— Ави
   (кайма горит)
— открой ютуб
```

Время ожидания меняется в `behavior.armedSeconds`.

---

## Имена

По умолчанию **«Хика»** и **«Ави»**. Распознаются с поправкой на то, как их
коверкает распознаватель: «Хико», «Кика», «Авви», «Авиа», «Avi», «Hika».

Обращения перед именем снимаются автоматически: `привет`, `здравствуй`, `эй`,
`слушай`, `окей`, `hey`, `hi`, `hello`, `ok`.

Свои имена — в `wake.words`. Если модель стабильно слышит имя как-то иначе,
добавь это написание в `wake.extraVariants` — сработает надёжнее любой
подстройки порогов.

## Глаголы запуска

Любой из них, или вообще без глагола.

**Русский:** открой, открыть, открывай, запусти, запустить, запускай, включи,
включить, включай, вруби, врубай, зайди, зайти, перейди, покажи, стартуй,
поставь, загрузи, вызови, дай

**Английский:** open, launch, start, run, show, goto, execute, bring, fire

Слова-паразиты выбрасываются: пожалуйста, давай, ну, там, короче, вот, мне,
please, just.

## Системные команды

Эти сравниваются с фразой целиком и срабатывают только при явном совпадении —
чтобы не перехватывать запуск программ.

| Что сказать | Что произойдёт |
|---|---|
| громче, погромче, прибавь звук, увеличь громкость | Громкость +8 % |
| тише, потише, убавь звук, уменьши громкость | Громкость −8 % |
| выключи звук, заглуши, без звука, mute | Переключить беззвучный режим |
| пауза, останови, продолжи, плей, play | Пауза или продолжение воспроизведения |
| следующий трек, следующая песня, дальше | Следующий трек |
| предыдущий трек, верни трек | Предыдущий трек |
| сверни всё, покажи рабочий стол | Свернуть все окна |
| сверни окно, спрячь окно | Свернуть активное окно |
| закрой окно, закрой это | Закрыть активное окно |
| заблокируй, заблокируй компьютер, блокировка | Заблокировать компьютер |
| скриншот, сделай скриншот, снимок экрана | Вызвать «Ножницы» |

Громкость меняется напрямую через звуковую подсистему Windows, а не нажатием
клавиш: шаг задаём мы, а не производитель клавиатуры. Управление
воспроизведением идёт мультимедийными клавишами — это единственный способ
достучаться сразу до всех плееров, от Spotify до браузера.

Окно закрывается корректным запросом, а не завершением процесса: программа
получит шанс спросить про несохранённое. Голосовая команда не должна ничего терять.

## Поиск

```
Ави, найди рецепт борща
Ави, загугли погоду в Москве
Ави, найди в гугле котиков
```

Глаголы поиска: найди, найти, поищи, ищи, загугли, гугли, погугли, search,
google, find, lookup.

Плюс обороты, после которых фраза уходит в поиск целиком:

```
Ави, что такое чёрная дыра
Ави, кто такой Тьюринг
Ави, как приготовить борщ
Ави, как поменять пароль в Windows
```

Оборот остаётся в запросе: «что такое чёрная дыра» ищется лучше, чем
обрубленное «чёрная дыра».

«Как дела», «как ты», «как думаешь» поиском не считаются — это разговор.

Поисковик меняется в `behavior.searchUrl`.

**Всё остальное в поиск не уходит.** Раньше уходило: любая непонятая фраза
открывала браузер. Задумывалось как вежливость — показать выдачу вместо
молчания, — а на деле случайно услышанная фраза открывала браузер
с собственными словами человека, и повторялось это столько раз, сколько
он говорил рядом с компьютером. Вернуть прежнее поведение можно через
`behavior.webSearchFallback`, но лучше не надо.

## Музыка и видео

Управление идёт не вслепую. Windows ведёт список сеансов воспроизведения —
тот самый, что виден в панели громкости, — и пауза адресуется тому, кто
действительно звучит, а не уходит наугад мультимедийной клавишей. Поэтому
работает и с YouTube во вкладке, и с Apple Music, и со Spotify, и в ответ
приходит название приложения.

```
Ави, пауза          Ави, стоп          Ави, хватит
Ави, продолжай      Ави, продолжи      Ави, возобнови
Ави, дальше         Ави, следующая     Ави, переключи
Ави, предыдущая     Ави, верни предыдущий трек
Ави, что играет     Ави, какая песня
Ави, включи музыку  Ави, врубай музон  Ави, запусти мою музыку
```

Односложные формы работают наравне с полными: «дальше» — это следующий
трек, «продолжай» — продолжить с того же места, «стоп» — тишина.

**«Включи музыку» умнее, чем кажется.** Если музыка приостановлена —
просто продолжит, это одно движение и ноль ожидания. Если плеер закрыт —
поднимет его и нажмёт «играть», когда тот объявится в системе (обычно
несколько секунд). И Apple Music, и Spotify по этому нажатию возвращаются
к тому, что слушали последним.

Оговорка, которую честнее сказать: выбрать *конкретный* плейлист снаружи
нельзя — плееры такого не позволяют никому. Каким приложением играть,
задаётся в настройках, «Поведение» → «Чем включать музыку»; пусто —
выберет само из установленного.

«Пауза» и «продолжи» разведены намеренно. Переключатель хорош на клавиатуре,
где видно, что играет; сказанное вслух «пауза» означает «пусть замолчит»,
и включить музыку в ответ — ровно противоположное тому, о чём просили.

Плееры, не ведущие список сеансов, управляются по-старому — мультимедийной
клавишей. Это происходит само, замечать переход не нужно.

## Числа: громкость и таймеры

```
Ави, сделай громкость тридцать
Ави, громкость на 50 процентов
Ави, поставь звук двадцать пять

Ави, поставь таймер на пять минут
Ави, напомни через десять минут
Ави, засеки полчаса
```

Числительные читаются словами и складываются как при счёте вслух:
«сто двадцать пять» — это 125. Единица измерения у таймера стоит после
числа; без неё подразумеваются минуты.

Таймеры живут в памяти и умирают вместе с программой. Это осознанно:
таймер, переживший перезагрузку и сработавший через сутки, пугает —
человек давно забыл, о чём просил.

## Переключение на открытое окно

```
Ави, переключись на хром
Ави, перейди в телеграм
Ави, разверни ворд
```

Это не то же самое, что «открой». Запуск открывает новое окно поверх той
работы, которая уже шла; переключение возвращает к ней. Если окна нет,
программа всё-таки запустится — отвечать отказом было бы формализмом.

Сопоставление нечёткое и по тем же правилам, что весь остальной разбор:
сравниваются и заголовок окна, и имя процесса, поэтому «на хром» находит
окно с заголовком «YouTube — Google Chrome».

## Ещё команды

```
Ави, который час
Ави, новая вкладка            Ави, закрой вкладку
Ави, обнови страницу          Ави, вернись назад
Ави, следующий рабочий стол   Ави, предыдущий рабочий стол
Ави, спящий режим
```

Выключения и перезагрузки здесь нет намеренно. Ассистент, срабатывающий
от похожего слова, не должен иметь права выключить компьютер: цена одной
ошибки — несохранённая работа за весь день. Сон обратим движением мыши.

## Продолжение без имени

После выполненной команды восемь секунд можно говорить дальше, не называя
имени:

```
Ави, поставь паузу
     а теперь громче
     дальше
```

Свечение при этом гаснет. Гореть всё это время оно не должно: горящая кайма
превращает «слушаю» в постоянный фон, а фон и есть то, от чего избавляются.

Правило здесь строже обычного, и это принципиально. Обычная команда защищена
именем: чтобы её выполнить, человек должен был обратиться. В окне продолжения
такой защиты нет, значит, её заменяет уверенность в самой команде. Проходят
только две вещи: готовая команда — «дальше», «стоп», «громче» — и запуск
программы, которая точно нашлась среди установленных. Ни поиска, ни разговора,
ни догадок: разговор рядом с компьютером не должен превращаться в череду
случайных действий.

Срок меняется в настройках, «Поведение» → «Слушать продолжение без имени».
Ноль — выключить.

## Как устроены фразы

Команды описаны не списком, а устройством. У «включи музыку» есть место
для глагола, место для уточнения и место для предмета, и в каждое подходит
свой набор слов:

```
[включи|поставь|запусти|врубай|давай]  [мне|мою|любимую]  музыку|музон|плейлист|треки
      необязательно                     необязательно            обязательно
```

Поэтому работают и те сочетания, которые никто не выписывал: «врубай музон»,
«поставь мой плейлист», «давай любимую музыку» — или просто «музыку».

Сравнение внутри слотов нечёткое и по звучанию, теми же правилами, что и весь
остальной разбор. А лишнее слово означает другую команду: «включи музыку
в стиме» — это Steam, а не музыка.

## Несколько команд в одном предложении

```
Ави, открой стим и сделай потише
Ави, поставь паузу и заблокируй компьютер
```

Резать по союзам вслепую нельзя: «Гарри Поттер и узник Азкабана» — одно
название, а не две команды. Поэтому решает не форма фразы, а исполнимость:
делится только тогда, когда каждая часть узнаётся сама — либо это готовая
команда, либо она находится среди установленных программ. Целая фраза при
этом имеет приоритет: если она узнаётся, делить нечего.

## Свои команды

Проще всего — в `config.json`:

```json
"custom": [
  {
    "phrases": ["работа", "рабочая почта", "корпоративка"],
    "target": "https://mail.company.ru/"
  },
  {
    "phrases": ["мой проект", "проект"],
    "target": "C:\\Users\\Я\\Projects\\hika\\hika.sln"
  },
  {
    "phrases": ["музыка", "включи музыку"],
    "target": "spotify"
  }
]
```

`target` — это ссылка, путь к файлу, имя программы или идентификатор
приложения Windows. Свои команды всегда выигрывают у встроенных при
одинаковой похожести.

Если записей много, удобнее вынести их в отдельный файл
`%APPDATA%\HIKA\catalog.json` того же формата, что встроенный каталог.
