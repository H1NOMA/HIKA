# Команды

## Как построена фраза

```
[обращение] ИМЯ [, ] [глагол] цель
```

Всё в квадратных скобках необязательно. Работают все варианты:

```
Ави, открой ютуб
Привет, Ави, открой ютуб
Эй, Хика, запусти ютуб
Ави ютуб
Hey Avi, open YouTube
```

**Имя можно назвать отдельно.** Скажешь просто «Ави» — кайма загорится
и будет ждать команду шесть секунд. Успел сказать за это время — сработает:

```
— Ави
   (кайма горит)
— открой ютуб
```

Время ожидания меняется в `behavior.armedSeconds`.

---

## Имена

По умолчанию **«Хика»** и **«Ави»**. Распознаются с поправкой на то, как их
коверкает распознаватель: «Хико», «Кика», «Авви», «Авиа», «Avi», «Hika».

Обращения перед именем снимаются автоматически: `привет`, `здравствуй`, `эй`,
`слушай`, `окей`, `hey`, `hi`, `hello`, `ok`.

Свои имена — в `wake.words`. Если модель стабильно слышит имя как-то иначе,
добавь это написание в `wake.extraVariants` — сработает надёжнее любой
подстройки порогов.

## Глаголы запуска

Любой из них, или вообще без глагола.

**Русский:** открой, открыть, открывай, запусти, запустить, запускай, включи,
включить, включай, вруби, врубай, зайди, зайти, перейди, покажи, стартуй,
поставь, загрузи, вызови, дай

**Английский:** open, launch, start, run, show, goto, execute, bring, fire

Слова-паразиты выбрасываются: пожалуйста, давай, ну, там, короче, вот, мне,
please, just.

## Программы

Работают три источника сразу:

1. **Встроенный каталог** — около 45 программ с русскими и английскими
   названиями (список ниже).
2. **Меню «Пуск»** — всё, что установлено на этом компьютере.
3. **Приложения Windows** — включая те, у которых нет ярлыка, из Microsoft Store.

Второе и третье обновляются в фоне каждые полчаса, так что свежеустановленная
программа появится сама.

## Системные команды

Эти сравниваются с фразой целиком и срабатывают только при явном совпадении —
чтобы не перехватывать запуск программ.

| Что сказать | Что произойдёт |
|---|---|
| громче, погромче, прибавь звук, увеличь громкость | Громкость +8 % |
| тише, потише, убавь звук, уменьши громкость | Громкость −8 % |
| выключи звук, заглуши, без звука, mute | Переключить беззвучный режим |
| пауза, останови, продолжи, плей, play | Пауза или продолжение воспроизведения |
| следующий трек, следующая песня, дальше | Следующий трек |
| предыдущий трек, верни трек | Предыдущий трек |
| сверни всё, покажи рабочий стол | Свернуть все окна |
| сверни окно, спрячь окно | Свернуть активное окно |
| закрой окно, закрой это | Закрыть активное окно |
| заблокируй, заблокируй компьютер, блокировка | Заблокировать компьютер |
| скриншот, сделай скриншот, снимок экрана | Вызвать «Ножницы» |

Громкость меняется напрямую через звуковую подсистему Windows, а не нажатием
клавиш: шаг задаём мы, а не производитель клавиатуры. Управление
воспроизведением идёт мультимедийными клавишами — это единственный способ
достучаться сразу до всех плееров, от Spotify до браузера.

Окно закрывается корректным запросом, а не завершением процесса: программа
получит шанс спросить про несохранённое. Голосовая команда не должна ничего терять.

## Поиск

```
Ави, найди рецепт борща
Ави, загугли погоду в Москве
Ави, найди в гугле котиков
```

Глаголы поиска: найди, найти, поищи, ищи, загугли, гугли, погугли, search,
google, find, lookup.

Поисковик меняется в `behavior.searchUrl`.

**Если команда ни на что не похожа, фраза уходит в поиск.** Молча проглотить
команду хуже, чем показать результаты: человек хотя бы увидит, что его
услышали. Выключается через `behavior.webSearchFallback`.

## Свои команды

Проще всего — в `config.json`:

```json
"custom": [
  {
    "phrases": ["работа", "рабочая почта", "корпоративка"],
    "target": "https://mail.company.ru/"
  },
  {
    "phrases": ["мой проект", "проект"],
    "target": "C:\\Users\\Я\\Projects\\hika\\hika.sln"
  },
  {
    "phrases": ["музыка", "включи музыку"],
    "target": "spotify"
  }
]
```

`target` — это ссылка, путь к файлу, имя программы или идентификатор
приложения Windows. Свои команды всегда выигрывают у встроенных при
одинаковой похожести.

Если записей много, удобнее вынести их в отдельный файл
`%APPDATA%\HIKA\catalog.json` того же формата, что встроенный каталог.
