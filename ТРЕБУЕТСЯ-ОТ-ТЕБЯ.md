## Шаг 1. Поставить .NET 9 SDK

Один раз. Дальше он не понадобится, если не будешь пересобирать.

Скачать: <https://dotnet.microsoft.com/download/dotnet/9.0> → **SDK x64**

Проверить, что встало:

```
dotnet --version
```

Должно вывести что-то вроде `9.0.xxx`.

## Шаг 2. Собрать

В папке с репозиторием:

```
git clone https://github.com/H1NOMA/HIKA.git
cd HIKA
git checkout claude/windows-voice-assistant-0pwhe8
dotnet publish src/Hika.App/Hika.App.csproj -c Release -o build
```

Результат — `build\Hika.exe`.

**Если сборка упала — не разбирайся сам, просто пришли мне весь вывод команды
целиком.** Это ровно та обратная связь, которая мне нужна.

> Альтернатива без установки SDK: зайди на
> <https://github.com/H1NOMA/HIKA/actions>, открой последнюю успешную сборку
> и скачай артефакт `hika-win-x64`. Там уже собранная программа.

## Шаг 3. Разрешить микрофон

Windows по умолчанию не пускает обычные программы к микрофону.

**Параметры → Конфиденциальность и защита → Микрофон**

Включить оба переключателя:
- «Доступ к микрофону»
- «Разрешить классическим приложениям доступ к микрофону» ← про этот забывают чаще всего

---

## Шаг 4. Первый запуск

```
build\Hika.exe
```

Программа уходит в трей (значок-кольцо рядом с часами) и начинает качать модели.

**Первый запуск занимает несколько минут** — качается около 200 МБ:
- модель детектора речи, ~2 МБ;
- модель распознавания `small`, ~181 МБ.

Обе кладутся в `%APPDATA%\HIKA\models` и больше не качаются.
Прогресс видно в журнале: правый клик по значку → «Журнал работы».

Когда в журнале появится `=== HIKA готова слушать ===` — можно говорить.

---

## Шаг 5. Проверить

Скажи, глядя на экран:

> **«Ави, открой ютуб»**

Что должно произойти:
1. как только начал говорить — по краям экрана появляется слабое свечение;
2. на слове «Ави» оно разгорается и начинает мерцать в такт голосу;
3. открывается YouTube;
4. кайма коротко вспыхивает зелёным и гаснет.

Попробуй ещё:

```
Хика, запусти телеграм
Ави, ютуб
Привет, Ави, открой ворд
Ави, сделай громче
Ави, сверни всё
Hey Avi, open Chrome
```

И отдельно проверь, что оно **не** реагирует на обычный разговор — просто
поговори рядом пару минут, не называя имён.

## Если что-то не работает

**Первым делом запусти диагностику** — она проверяет всю цепочку и пишет отчёт:

```
build\Hika.exe --diagnose
```

Скажи в микрофон «Ави, открой ютуб», когда попросит. Программа покажет:
- какие микрофоны есть в системе и какой выбран;
- доходит ли до неё звук (живая полоска уровня);
- считает ли она это речью;
- **что именно она расслышала** ← самое ценное;
- нашла ли имя и во что превратила команду.

Отчёт сохранится в `%APPDATA%\HIKA\диагностика-<дата>.txt`.
**Пришли мне этот файл целиком** — в нём есть всё, что нужно для разбора.

### Частые случаи и что с ними делать

**Не слышит имя.** Посмотри в отчёте строку «Распознано». Если там вместо «Ави»
написано что-то другое — скопируй это в `%APPDATA%\HIKA\config.json`:

```json
"wake": {
  "words": ["хика", "ави"],
  "extraVariants": ["обои", "авиа", "а ви"]
}
```

Это самый надёжный способ научить программу твоему произношению.

**Срабатывает само на обычную речь.** Уменьши `wake.tolerance` с `0.34` до `0.25`.

**Звука нет вообще** (в отчёте пиковый уровень около нуля). Три причины
по убыванию частоты: выбран не тот микрофон, микрофон приглушён в микшере
Windows, слишком тихий вход. Первое лечится вписыванием части имени нужного
устройства в `audio.device`, третье — поднятием `audio.gain` до `2.0`–`3.0`.
Список микрофонов: `Hika.exe --list-audio`

**Свечение не появилось.** Проверь `overlay.enabled` в настройках. Если там
`true`, а каймы нет — напиши мне, это как раз та часть, которую я не мог
проверить. В журнале будут строки с пометкой `overlay`.

**Свечение слишком яркое или мешает.** `overlay.maxOpacity` — от `0.55`
можно уйти вниз до `0.3`. `overlay.thickness` — толщина каймы.

**Плохо распознаёт русский.** Смени модель на большую в `config.json`:

```json
"speech": { "model": "largev3turbo", "quantization": "q5_0" }
```

Это ещё 547 МБ загрузки и заметно медленнее на процессоре — но если у тебя
есть видеокарта NVIDIA, см. следующий раздел, там всё становится быстро.

## Если у тебя NVIDIA

Распознавание уедет на видеокарту и станет в разы быстрее — тогда имеет смысл
сразу брать большую модель.

Нужен установленный **CUDA 12 Runtime**, потом пересобрать так:

```
dotnet publish src/Hika.App/Hika.App.csproj -c Release -o build -p:HikaCuda=true
```

Для видеокарт AMD и встроенной графики Intel то же самое, но `-p:HikaVulkan=true`.

## Чего в этом билде ещё нет

Честный список, чтобы не искал:

- **Ассистент не отвечает** — ни голосом, ни текстом. Ты сам так просил;
  вся отдача — свечением и действием.
- **Только запуск программ и сайтов** плюс десяток системных команд
  (громкость, музыка, свернуть, заблокировать). Управления содержимым
  чужих окон пока нет.
- **Свечения не будет поверх игр в полноэкранном режиме.** Это неустранимо
  без перехвата DirectX, а за такое банят античиты. В оконном режиме
  без рамки всё работает.
- **Нет окна настроек** — всё правится в `config.json`. Файл перечитывается
  на лету, перезапускать программу не нужно.
- **Программа не подписана.** SmartScreen при первом запуске покажет
  «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
  Это лечится покупкой сертификата подписи, и делать это имеет смысл, только
  если соберёшься раздавать программу другим людям.
